# Language support / Dil desteği

Portfolio follows XenForo's native language selection. Import `languages/Turkish.xml` or `languages/English.xml` into the matching XenForo language (or a child language).

Interface text, security/moderation screens, buttons, status labels and settings are translated. Member-created portfolio titles, descriptions, comments and tags are content and are not automatically translated.

Yeni kullanıcıya görünen sabit metinler XenForo phrase sistemi kullanılmadan template/PHP/JS içine eklenmemelidir.
